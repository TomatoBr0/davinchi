# Deployed Da Vinci web app

This directory preserves the existing `da-vinci.caleb-darjany.workers.dev` Worker and browser assets recovered from its deployed modules on 2026-11-20. It is separate from the offline Python prototype in the repository root. `public/` is the editable browser source; `assets.js` is generated by `node build.mjs`.

## Writing reminders

Web Push runs independently of ChatGPT tasks and works with the app closed. Open the app, choose **Enable writing reminders**, allow notifications, then **Send test**. On iOS/iPadOS 16.4 or later, add Da Vinci to the Home Screen and enable notifications from that installed app. Each device subscribes independently; **Turn off on this device** removes its subscription.

Five reminders daily at **09:00, 12:00, 15:00, 18:00, 21:00 America/Los_Angeles**, matching the retired ChatGPT reminder and staying inside 8 AM–10 PM. Cron `0,5,10 * * * *` runs in UTC; the handler applies the Pacific timezone and DST. A 15-minute window permits retries; successful sends are deduplicated per device/slot, expired devices are removed, and the delivery TTL is 15 minutes to avoid stale reminders. These are best-effort notifications subject to browser delivery and device Focus settings, not guaranteed alarm times.

The short reminder suggests the least collected motion-group focus when available, falling back to a general five-minute writing prompt. No AI request or recording change is made to send reminders. This uses a simple sample-count ranking, rather than the old ChatGPT task's more detailed analysis.

`davinci_push_config` holds the VAPID key pair (private key stays server-side). `davinci_push_subscriptions` holds browser endpoints, keys and delivery slots. Both tables are created automatically without changing existing recordings. Push endpoints are limited to supported browser push providers. The app retains its existing public single-user access model.

## Checks and deployment

Requires Node 22+ for the SQLite-backed tests:

```sh
node --test tests/*.test.js
node build.mjs
```

Deploy the ES modules `worker.js`, `assets.js`, `practice.js`, `words.js`, `push.js`, and `reminders.js` to the existing **da-vinci** Worker. Its DB binding must remain the existing Da Vinci database; retain its AI and secret bindings. The Cloudflare **Replace Worker Script Content** API (`PUT /accounts/{account_id}/workers/scripts/da-vinci/content`, multipart main_module `worker.js`) preserves existing settings/bindings. Configure cron `0,5,10 * * * *` using the script schedules API. Do not replace production bindings or recreate its database.

The regression tests check Pacific/DST timing, quiet hours, subscription validation, real SQLite persistence/deduplication/retries/removal, and Web Push signature/encryption through recipient-side decryption. Actual permission prompts, iPhone installation and delivery require a real device using **Send test**.
