Calibration wizard
Do the five steps in order after every power-up. Use measured values only. Arrow keys jog when this tab is open: Left/Right X, Up/Down Y, PageUp/PageDown Z.

    
Printable sheet: calibration_sheet.pdf. Print at 100% / actual size, not fit-to-page.

  


  

    
1. Enable motors
Sends steps/mm, Z travel and pen heights while disarmed, then M17 enables the drivers. Bake-in values are 5, 5 and 160 steps/mm; if a 1 mm jog moves much further than 1 mm, stop and lower it. Start with 0.1 mm jogs.

3. Jog to the far corner, save max
Move to the top-right travel corner of the bed, then save it (M211). This also marks the machine calibrated.

4. Draw the test square
Load a dark pen at the pen-down height. The 100 mm square and crosshair start at the origin you set. Let the ink dry before measuring.

    

  


  

    
5. Enter the measured size
Measure the drawn square with a ruler. New steps/mm = old x 100 / measured. Applying disarms the motors and clears the origin (M18, then M92).
